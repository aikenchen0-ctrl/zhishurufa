# 输入法 SDK 第一阶段实施计划

目标：在同文根工程中复用一套输入实现，生成独立输入法、SDK 和不同包名的宿主演示。

架构：`ime-sdk` 包含原 Java/Kotlin 实现、主题资源及 JNI 构建；`app` 是独立安装入口；`sample-host` 使用自己的 Application 调用 SDK 初始化。原生和词库子模块保留原路径，避免破坏已有 Git 依赖关系。

- [x] 核对现有迁移、子模块和失败日志。
- [x] 修复子模块目录，保留 JNI Java 包名。
- [x] 修复库构建插件、依赖、生成资源和既有测试接入。
- [x] 提供幂等初始化与运行时宿主包名，取消强制继承 Application。
- [x] 分离宿主清单和 SDK 清单，验证构建包名及存储边界检查。
- [x] 生成真实词库资源，检查 APK/AAR 不包含链接占位文本。
- [x] 执行单元测试，构建 AAR 和两个 APK，检查原生库与清单。
- [x] 编写接入说明并记录尚未完成的布局、真机验证项目。

验证命令：`gradlew.bat :ime-sdk:testDebugUnitTest :ime-sdk:assembleDebug :app:assembleDebug :sample-host:assembleDebug -PbuildABI=arm64-v8a`。

本轮只交付 SDK 构建和接入基线。九宫拼音、双拼、五笔字型必须以可输入的方案与词库组合另行验收，不能以现有数字九宫或笔画布局代替。保留既有代码许可证声明，按用户要求不再以许可证作为本轮选型条件。
