- [x] 核查现有产物、崩溃日志和设备环境。
- [x] 修复确定的原生线程越界，增加设备回归测试。

- [x] 构建双架构发布库，执行代码与资源检查。
- [x] 验证 R8 压缩后的宿主与原生接口。

本轮结果：401 项单元测试通过，SDK 与宿主发布构建完成；独立测试 AVD 上，x86_64 冷启动与 ARM64 转译各十四组设备测试通过，日志和截图见发布验证文档。编辑器快照及写回已添加密码过滤、会话校验与组合态保护；草稿本地保存为显式调用、不参与系统备份。内置 AI 支持 Grok、OpenAI 和兼容代理，默认关闭，密钥由 Keystore 加密保存且不进入 APK，四类 AI 操作、流式响应和 SDK 内置重试已接入。物理 ARM64 验收、历史 SIGSEGV 唯一根因、正式发布签名仍未完成。

保持高内聚低耦合：线程串行化属于 Rime 层；发布与签名属于构建层；宿主业务继续只通过 SDK 公开接口接入。本轮不把缺少真机变成无限重试，也不修改无证据关联的第三方引擎算法。
